Handwritten diagrams and difficult text can be missed by OCR; use the linked PDF and its page references to check the original.

## Conversion notes

- Each note links to its source PDF and includes page references when they were recoverable.
- OCR confidence varies, especially for handwriting and diagrams. Unclear text is not silently treated as fact.
- Source diagrams and worked examples remain in the PDF; check the cited page when exact labels, code, or numeric values matter.
